Programs and assignments completed as part of the Logic Building batch.

## Repository Structure

- `Assignments/Assignment_1/` — Solutions for Assignment 1.
- `Assignments/Assignment_2/` — Solutions for Assignment 2.
- `Classwork/Day_01/` — Classwork programs.

## File Naming Convention

- `program1_1.c` — Assignment 1, Question 1.
- `program1_2.c` — Assignment 1, Question 2.
- Continue the same naming pattern for the remaining questions.

## How to Compile and Run

Install GCC on your computer.

Compile a C program:

```bash
gcc program1_1.c -o program1_1
```

Run on Windows PowerShell:

```powershell
.\program1_1.exe
```

## Coding Standards

- Write readable and properly formatted code.
- Use meaningful function and variable names.
- Include the required code header and comments.
- Test programs before submitting them.
